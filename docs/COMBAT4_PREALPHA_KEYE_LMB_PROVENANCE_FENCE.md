If the same actor's independently sourced existing v1 `InputIntent.heavy_attack` edge arrives while that light is still unlanded, the original `begin_requested_action` upgraded it to `HeavyAttackWindup` **without a correlated v2 LMB gesture UPGRADE**. This is an actual source/actor ambiguity, not an actual live exploit or a claim that the inactive protocol caused a production failure.

That private flag is **false for all original v1 actors** and is only set by the uncalled review-only v2 World bridge. True original v1 KeyE, native Space+LMB, roll, block/parry, HIT/HP constants and authoritative damage remain unchanged. ## Combat4 proposed canonical source signoff (CONDITIONAL)

- **LMB source 0**, v2 EVENT `0x11`, retains original 16-byte PRESS/UPGRADE/RELEASE/CANCEL. Server light windup begins on admitted PRESS. Same gesture UPGRADE only if original light unlanded; 320ms heavy READY from server time; single matching RELEASE strikes heavy, never on hold. Early release resolves one light, CANCEL cannot invent a hit.
- **Standalone KeyE source 1** is a **future-only, not yet implemented negotiated byte3 extension** proposed by Core8A [#727](https://github.com/tehki/myaso/pull/727). Combat recommends a separate independent KeyE action source, **not LMB UPGRADE**. Preserve existing documented gameplay: KeyE PRESS starts ordinary original 320ms heavy windup, which commits normally when ready, even if the key is released earlier; KeyE RELEASE/CANCEL must not be treated as the special LMB heavy RELEASE. Core8A/Main/Core8C/UI10 must formally agree before changing decoder to accept byte3=1. Until then existing decoder `decode_event` must reject KeyE-source messages with `DecodeError::Reserved`; this candidate does not relax it.
- The single agreed server-issued actor/connection generation determines ownership (Core8C) and the source/gesture identity must be bound throughout Core8A ingress replay+ACK; a standalone E source cannot upgrade a concurrently pending LMB. On mixed sources, choose an explicit deny/defer/arbitration policy, and suppress legacy E/LMB attack flags atomically for negotiated v2 sessions **without** suppressing independent v1 peers. No direct wire `Command` permitted.
