# UI 10 — Original Silver Knight Pre-Alpha four-browser acceptance

**Scope:** Pre-Alpha 0.1 main directive [#695](https://github.com/tehki/myaso/issues/695); implementation parent [#698](https://github.com/tehki/myaso/pull/698). This PR is a **test-only direct child**, not a gameplay feature, no source changes to server, browser, Combat or original five atlases. No main merge/deploy/ingress/config changes.

`scripts/ui_prealpha_four_native_silver.mjs` starts the **real compiled Rust authoritative arena** on ephemeral loopback with certificate-pin, serves existing `web/` statically, and launches four **independent genuine native WebDriver browser sessions** (Chrome/Firefox/Chrome/Firefox) on one CI host using the actual `?knights=1` official Pre-Alpha toggle. No Greyhaven, rack, NPC, items, World, IDR, alternate server or fake fighter snapshots.

A passive, narrowly scoped instrument around `CanvasRenderingContext2D.drawImage` counts **only original decoded `/assets/knights/silver_*.webp`** source image paints onto **the actual `#arena` canvas**. It delegates to original browser `drawImage`, never mocks a sprite or alters gameplay. Each of the four players must have a real server-owned `Online - player #NN - server tick` state, four true scoreboard participants, 12+ actual painted Silver sprite image calls, 4+ painter calls in a continuous small render burst (local and remote bodies), correct original source atlas dimensions and no substitution images. A genuine native W key is held and released on player A while server ticks and Knight paints continue.

This only proves: real Silver body pixels are actually painted from original first-party WebPs for 4 actual live browser sessions in the same arena, and the original UI keeps rendering and accepting native movement. It does **not** certify true human input across machines, instant LMB light, delayed full-charge heavy, full authenticated impact, two-host reachability, rollback, public playable status or original Combat M41/M147/M155/M194 acceptance. The unsupported Silver kick/attack/stun/death actions still use original source Combat fallback, not fabricated animations.

The official Pre-Alpha launch remains **HOLD** until Combat [#696](https://github.com/tehki/myaso/issues/696) preserves instant-light/held-heavy single-gesture authority, protected quality, real Chrome/Firefox and independent-host multiplayer, immutable package and rollback. Existing merged-main and direct legacy Combat test URLs must stay pixel-identical without `knights=1`. Main Orchestrator only may integrate or deploy.

As native code does not run on the X230i host (Chromium SIGILL at startup), native success must be established only via exact-head GitHub Actions and **not** inferred from Node/unit tests.
