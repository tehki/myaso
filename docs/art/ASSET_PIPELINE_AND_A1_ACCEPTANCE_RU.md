# myaso.io — Production Pipeline, Milestone A1

Источник решений: [BLOOD_AND_IRON_ART_DIRECTION_RU.md](./BLOOD_AND_IRON_ART_DIRECTION_RU.md). Этот документ — первый **воспроизводимый инженерный контракт для art team**, а не объявление, что реалистичный мир готов.

## Исходные артефакты

| Файл | Роль |
|---|---|
| `assets/environment/greyhaven/art-manifest.v1.json` | координаты, материалы, реестр 55–70 необходимых модулей/вариантов, графические ограничения |
| `tools/art/build_red_lion_blockout.py` | редактируемый генератор 3D-модульного blockout, без сетевых зависимостей |
| `assets/environment/greyhaven/red_lion_blockout.obj` | детерминированная 3D-геометрия Red Lion для Blender |
| `assets/environment/greyhaven/red_lion_blockout.mtl` | цвета-прототипы материалов, **не** финальные PBR |
| `tests/art-direction-a1.test.mjs` | структурные/масштабные проверки в обычном `node --test` |
| `web/red-lion-art-preview.html` | интерактивный ортографический 3D-просмотр OBJ с временным углом/масштабом, без внешних библиотек |
| `docs/art/red_lion_a1_preview.png` | проверенный Chromium скриншот для быстрого GitHub-ревью |

Воспроизвести исходную геометрию:
```sh
python3 tools/art/build_red_lion_blockout.py
```
Проверить в браузере: `python3 -m http.server 8080` из корня репозитория, затем `http://localhost:8080/web/red-lion-art-preview.html`. Это самостоятельный QA preview, **не** игровой рендер.

Код не использует случайность и не требует GPU. OBJ/MTL сохраняются в одном каталоге; reimport в Blender не теряет material IDs.

## Масштаб A1

- 1 world unit = **0.025 метра** только для 3D authoring.
- Живой сервер: круг столкновения рыцаря **18 world units** (= 0.45 м радиус **только по художественной шкале**).
- Исходная карта: 8192 × 8192; визуальный `ARENA_VIEW_ZOOM=0.84`.
- Red Lion exterior из планируемого PR #336: 250 × 170 world units = **6.25 × 4.25 м**.
- **Объёмный blockout**: 6.25 × 4.25 м стены и крыша, выступы до ~6.81 м поперёк, ступени/бочки выходят за фасад.
- Портал снаружи: (4365, 4075); внутренний проход (390, 550), интерьер **780 × 620 world units**, отдельная карта.
- Центр входа на фасаде (+Y в исходном OBJ): world x=4365; ступени и бочки — **визуально**, коллизии/доступ контролирует будущий авторитетный сервер.

## Порядок импорта для environment artist

1. Импортировать OBJ в Blender; убедиться, что 1 OBJ единица = 1 м, Z вверх; вход находится с положительной стороны Y.
2. Создать ассетную коллекцию RedLion/Source; оставлять исходник в системе контроля версий.
3. Привести крышу, балки, ставни, камни, черепицу к целевым правдоподобным материалам. Использовать FBX/glTF только для промежуточного обмена, источник — Blender/сцены в репозитории. Все внешние текстуры — с явными автором, лицензией и местом покупки/создания; нельзя переносить чужие ассеты без разрешения.
4. Отделить 3D-геометрию **крыш, стен, ground-contact shadow** для дальнейшей прозрачности при перекрытии персонажа.
5. Согласовать ортографическую export-камеру с текущим 2D top-down view и реальными knights; **не фиксировать выдуманный pitch**.
6. Bake AO/свет, получить слои с альфой и consistent pivot у основания; проверить, что тайлы не смещаются при `0.84` zoom и разных DPR.
7. Сохранить alpha-edged compressed WebP atlases с controllable draw order; glTF-runtime only if performance benchmark proves benefit.
8. Не добавлять portal/collision телепортацию через художественные ассеты. Сетевые зоны и стены — отдельный проверяемый контракт.

## QA-гейты A2

До начала массового производства требуется визуальное ревью **в одном кадре**: Red Lion + три дома + Silver Knight + T1 Sentinel; затем тест в реальном Chrome/Firefox, проверка угла экспорта и читаемости атак.

Рекомендуемые кандидаты бюджетов (пока **не измерены**):
- preview атласы: не больше 2048×2048 каждый, 4k исключение только после бенчмарков;
- 24/32 видимых чанка как начальная memory-конфигурация, число подтверждается профилированием;
- минимум повторных draw calls, стабильные materials, переработка distant textures;
- 60 FPS desktop — **цель**, не текущая метрика; мобильная скорость отдельный релизный блокер.

## Release/protection policy

Эта A1-ветка — **только документы + исходная архитектурная геометрия и тесты**. Ни один новый texture/OBJ не загружается игровым клиентом по умолчанию. PR #326 (knights), #336 (fixed map) и #340/#341 (зоны) независимы и не должны быть спрятаны в один art-PR. Отдельное разрешение требуется на production deploy. Red required `quality` — не merge.
